## Development

Today's work involved writing a lot more code than I expected.

Each of these sections has its own folder with multiple files, and every component slowly started growing into hundreds of lines of code.

Even though the landing page looks simple from the outside, there's a surprising amount of work happening behind the scenes to keep everything clean, reusable, and easy to maintain.

I'm starting to understand why modern websites are split into so many components instead of keeping everything inside one massive file.

---

## What I Learned

One thing I'm noticing is that a polished UI isn't built by one big component.

It's built from lots of smaller components working together.

At first, creating so many files felt unnecessary, but now it actually makes the project much easier to organize and expand.
