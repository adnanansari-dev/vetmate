# REON Design System

## Overview

This document defines the visual guidelines for REON. Following a consistent design system helps maintain a unified experience across the application as new features are added.

|----------|------:|
| Buttons | 12px |
| Cards | 16px |

---

## Motion

- Default transition: 250ms ease-out
- Hover scale: 1.02
- Hover lift: -2px
- Use subtle animations only when they improve usability.

---

## Design Principles

- Prioritize clarity over decoration.
- Keep interfaces simple and consistent.
- Use whitespace generously.
- Highlight important actions with the accent color.
- Motion should support interactions, not distract from them.
